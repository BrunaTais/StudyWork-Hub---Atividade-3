# StudyWorkHub – Etapa 3

## Sobre a atividade

Nesta etapa foi realizada a implementação das interfaces gráficas e das funcionalidades do sistema StudyWorkHub, utilizando Java e NetBeans.

O objetivo foi transformar o projeto de interfaces desenvolvido na etapa anterior em uma aplicação funcional, permitindo a interação do usuário com os elementos das telas e a navegação entre as funcionalidades do sistema.

## Desenvolvimento

Durante esta etapa foram desenvolvidas:

- Interfaces gráficas da aplicação;
- Interações entre os elementos das telas;
- Navegação entre as telas;
- Implementação das funcionalidades previstas no projeto;
- Organização das classes do sistema.

## Tecnologias utilizadas

- Java
- NetBeans
- Java Swing

## Diagrama UML

O projeto possui um diagrama UML com a estrutura das classes utilizadas no sistema.

## Arquivos

O projeto contém os arquivos necessários para execução e desenvolvimento da aplicação no NetBeans.
